# ecModels, `gecko4` branch

Enzyme-constrained models built with [geckopy](https://github.com/SysBioChalmers/geckopy) (GECKO 4).

| model | based on | folder |
|-------|----------|--------|
| ecYeastGEM | yeast-GEM 9.1.1 | [`ecYeastGEM/`](ecYeastGEM/) |

Each folder holds the build script, inputs and reports for one model. The model file itself is attached to that model's [release](https://github.com/SysBioChalmers/ecModels/releases).
